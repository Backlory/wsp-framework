# Waterjet Scale Probe (WSP)

This repository contains resources and code for the paper *"From Learning to Grounding: Waterjet Scale Probe Framework for Metric Reconstruction in Monocular Endoscopy"*.

## Release Roadmap

Materials are currently being organized and will be released in phases:

- [x] Calibration board design and 3D printing models for hardware (Available)
- [ ] Datasets (Work in progress)
- [ ] Core algorithm code (To be released)

## Overview

- `3D Printing Model/`: 3D printing files (STL) for the endoscope holder and calibration setup.
- `Jet Calib Board Design/`: Multi-scale calibration board patterns and 3D corner coordinates.
- `dataset/`: Datasets for proof of principle (To be released).
- `code/`: Core algorithms and processing scripts (To be released).
